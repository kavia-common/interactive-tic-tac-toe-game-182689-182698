# Tic Tac Toe – Ocean Professional

This app provides a fully client-side Tic Tac Toe experience using Next.js (App Router) and Tailwind CSS.

How to run:
- npm run dev
- Open http://localhost:3000

How to play:
- Player X starts first.
- Click an empty square or press Enter/Space while focused to place your mark.
- The banner above the grid shows whose turn it is, and announces a win or draw.
- Click “Reset Game” to start a new round.

Testing hooks:
- Squares: data-testid="square-0" .. "square-8"
- Status banner: data-testid="status"
- Reset button: data-testid="reset-button"

Theme:
- Ocean Professional (primary #2563EB, secondary/success #F59E0B, error #EF4444)
- Background #f9fafb, surface #ffffff, text #111827.
- Subtle gradients, rounded corners, and clean layout.
